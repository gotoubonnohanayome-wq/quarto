Distribusi sampling adalah konsep teoretis: dalam praktik kita hanya memiliki satu sampel. Na- mun dengan simulasi kita dapat “melihatnya”.

2.1.1 Populasi Simulasi

Kita memakai populasi 20.000 mahasiswa dengan variabel waktu layar harian (jam) yang menjulur kanan – bentuk yang sengaja dipilih jauh dari lonceng.

set.seed(909)
N <- 20000

mu <- mean(populasi)
sigma <- sqrt(mean((populasi - mu)^2)) # SD populasi (pembagi N)
c(N = N, mu = round(mu, 3), sigma = round(sigma, 3))
        N        mu     sigma 
20000.000     5.010     3.551

Populasi dan satu sampel sama-sama menjulur kanan, tetapi distribusi rata-rata sampel jauh lebih sempit dan hampir berbentuk lonceng. Inilah inti pertemuan ini.

2.2.1 Pengaruh Ukuran Sampel

set.seed(2)
n_list <- c(5, 20, 80)
par(mfrow = c(1, 3))
for (nn in n_list) {
rata <- replicate(5000, mean(sample(populasi, nn)))
hist(rata, breaks = 40, col = "#a1d99b", border = "white", xlim = c(1, 10), freq = FALSE,
main = paste0("n = ", nn, " (SE = ", round(sigma / sqrt(nn), 2), ")"),
xlab = "Rata-rata sampel")
curve(dnorm(x, mu, sigma / sqrt(nn)), add = TRUE, col = "firebrick", lwd = 2)
abline(v = mu, lty = 2)
}
par(mfrow = c(1, 1))

Kurva merah adalah distribusi normal dengan mean μ dan SD σ/√n. Semakin besar n: (1) distribusi semakin sempit, dan (2) bentuknya semakin mendekati normal meskipun populasinya menjulur kanan.

2.3 Central Limit Theorem (CLT)

Central Limit Theorem. Jika sampel acak berukuran n diambil dari populasi sem- barang bentuk dengan mean μ dan simpangan baku σ (terhingga), maka untuk n

yang cukup besar, distribusi sampling ̄x mendekati normal:

[ {x} N(,) ]

CLT adalah alasan mengapa distribusi normal muncul di mana-mana dalam statistika inferensial – bukan karena data selalu normal, tetapi karena rata-rata dari data cenderung normal.

2.3.1 Demonstrasi pada Tiga Bentuk Populasi

set.seed(3)
pop_bentuk <- list(
"Seragam" = runif(20000, 0, 10),
"Menjulur kanan" = rexp(20000, rate = 0.5),
"Bimodal" = c(rnorm(10000, 2, 0.8), rnorm(10000, 8, 0.8))
)
ukuran <- c(2, 5, 30)
par(mfrow = c(4, 3), mar = c(3, 3, 2.5, 1))
for (nama in names(pop_bentuk)) {
hist(pop_bentuk[[nama]], breaks = 40, col = "#9ecae1", border = "white",
main = paste("Populasi:", nama), xlab = "", ylab = "")
}
for (nn in ukuran) {
for (nama in names(pop_bentuk)) {
rata <- replicate(3000, mean(sample(pop_bentuk[[nama]], nn)))
hist(rata, breaks = 35, col = "#a1d99b", border = "white",
main = paste0(nama, ", n = ", nn), xlab = "", ylab = "")
}
}
par(mfrow = c(1, 1), mar = c(5, 4, 4, 2) + 0.1)

Baris pertama adalah populasi; baris berikutnya adalah distribusi sampling ̄x untuk n = 2, 5, dan 30. Populasi seragam sudah tampak lonceng pada n = 5; populasi bimodal masih bergelombang pada n = 2 tetapi lonceng pada n = 30; populasi menjulur kanan membutuhkan n terbesar untuk menghilangkan kemencengannya.

2.3.3 Menghitung Peluang dengan CLT

Contoh: Jika diambil sampel acak 40 mahasiswa, berapa peluang rata-rata waktu layarnya melebihi 5,5 jam?

[ z= ]

[ P({x}>5,5)=P(Z>z) ]

se40 <- sigma / sqrt(40)
z_55 <- (5.5 - mu) / se40
c(SE = round(se40, 4), z = round(z_55, 3),
Peluang_CLT = round(1 - pnorm(z_55), 4),
Peluang_simulasi = round(mean(banyak_rata > 5.5), 4))
              SE                z      Peluang_CLT Peluang_simulasi 
          0.5615           0.8730           0.1913           0.1803

Perbandingan: peluang seorang mahasiswa (bukan rata-rata 40 orang) memiliki waktu layar di atas 5,5 jam jauh lebih besar:

mean(populasi > 5.5)
[1] 0.35175

Individu sangat bervariasi, tetapi rata-rata dari banyak individu jauh lebih stabil.

2.5.2 Hukum Akar Kuadrat

Karena SE ∝ 1/√n, untuk membagi dua SE dibutuhkan sampel empat kali lipat. Presisi semakin mahal: menambah n dari 100 ke 400 memberi keuntungan yang sama dengan dari 400 ke 1.600.

̄x ± tα/2, n−1 s √ n

Contoh Perhitungan

moe <- t_krit * se_hat
c(n = n1, x_bar = round(xbar, 3), s = round(s, 3), SE = round(se_hat, 3),
t_kritis = round(t_krit, 3), MoE = round(moe, 3),
Bawah = round(xbar - moe, 3), Atas = round(xbar + moe, 3))
       n    x_bar        s       SE t_kritis      MoE    Bawah     Atas 
  40.000    4.915    3.019    0.477    2.023    0.966    3.950    5.881

[1] 3.949947 5.881053
attr(,"conf.level")
[1] 0.95

Laporan: “Rata-rata waktu layar mahasiswa diperkirakan 4.92 jam per hari, dengan selang keper- cayaan 95% antara 3.95 dan 5.88 jam (n = 40).”

̂p ± zα/2√ ̂p(1 − ̂p) n syarat: n ̂p ≥ 10 dan n(1 − ̂p) ≥ 10

2.10 Kesalahan Umum dalam Sampling Distribution dan Estimasi

  1. Menyamakan distribusi sampel dengan distribusi sampling – yang pertama berisi data individu, yang kedua berisi statistik dari banyak sampel.

  2. Mengira CLT membuat data menjadi normal – CLT berbicara tentang distribusi rata- rata, bukan data individu.

  3. Menganggap n ≥ 30 selalu cukup – data yang sangat menceng atau beroutlier bisa mem- butuhkan lebih.

  4. Menyamakan SD dan SE – SD mengukur keragaman individu; SE mengukur ketepatan taksiran.

  5. Memakai z padahal σ tidak diketahui dan n kecil – gunakan distribusi t.

  6. Menafsirkan CI sebagai peluang parameter berada di dalam selang tertentu, atau sebagai rentang nilai individu.

  7. Membulatkan ukuran sampel ke bawah – selalu bulatkan ke atas.

  8. Mengira ukuran populasi menentukan ukuran sampel – untuk populasi besar, yang menentukan adalah margin of error, tingkat kepercayaan, dan variabilitas.

  9. Mengira sampel besar menghilangkan bias – ukuran sampel hanya mengecilkan galat acak.

  10. Memakai pendekatan normal untuk proporsi saat n ̂p atau n(1 − ̂p) kurang dari 10.

  11. Melaporkan point estimate tanpa selang atau n – pembaca tidak dapat menilai ketepatannya.

2.13 Rangkuman dan Kesimpulan

  1. Distribusi sampling menggambarkan bagaimana sebuah statistik bervariasi dari sampel ke sampel; ia adalah fondasi seluruh statistika inferensial.

  2. ̄x dan ̂p adalah penaksir tak bias dengan SE masing-masing σ/√ n dan √p(1 − p)/n.

  3. CLT menjamin distribusi ̄x mendekati normal untuk n cukup besar, apa pun bentuk popu- lasinya; makin menceng populasi, makin besar n yang dibutuhkan.

  4. SE bukan SD: SE mengecil sebanding 1/√ n – presisi dua kali lipat membutuhkan sampel empat kali lipat.

  5. Selang kepercayaan = point estimate ± nilai kritis × SE. Gunakan z bila σ diketahui, t bila σ ditaksir. Kepercayaan 95% adalah sifat prosedur, bukan peluang untuk satu selang.

  6. Ukuran sampel dapat direncanakan dari margin of error yang diinginkan – tetapi tidak dapat menyembuhkan bias sampling.
