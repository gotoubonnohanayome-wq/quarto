1.1.1 Ilustrasi: Apakah Mesin Pengisi Masih Tepat?

Melanjutkan latihan Pertemuan 9: mesin kopi bubuk seharusnya mengisi rata-rata 250 gram dengan σ = 6 gram. Sampel 36 kemasan menghasilkan ̄x = 247,6 gram. Apakah mesin perlu dikalibrasi, atau selisih 2,4 gram itu sekadar kebetulan sampling? Jika mesin benar (μ = 250), maka menurut CLT ̄x ∼ N(250, 6/√36 = 1). Kita lihat seberapa “jauh” 247,6 dari distribusi tersebut:

# Simulasi Distribusi Sampling Rata-rata

mu0 <- 250
sigma <- 6
n <- 36
xbar <- 247.6

# Menghitung Standard Error
se <- sigma / sqrt(n)

# Simulasi distribusi sampling jika H0 benar
set.seed(10)

xbar_jika_H0 <- replicate(
  100000,
  mean(rnorm(n, mean = mu0, sd = sigma))
)

# Membuat histogram
hist(
  xbar_jika_H0,
  breaks = 60,
  col = "#c6dbef",
  border = "white",
  freq = FALSE,
  main = "Distribusi x-bar jika mesin bekerja benar (mu = 250)",
  xlab = "Rata-rata 36 kemasan (gram)"
)

# Menambahkan garis rata-rata sampel dan posisi simetris
abline(
  v = c(xbar, 2 * mu0 - xbar),
  col = "firebrick",
  lwd = 2,
  lty = c(1, 2)
)
mean(abs(xbar_jika_H0 - mu0) >= abs(xbar - mu0)) # seberapa sering selisih sebesar ini terjadi
[1] 0.01579

Jika mesin benar, rata-rata yang meleset 2,4 gram atau lebih (ke arah mana pun) hanya terjadi sekitar 1.6% dari waktu. Angka inilah yang disebut p-value. Karena sangat jarang, kita punya alasan kuat untuk meragukan bahwa mesin bekerja benar.

1.3 Komponen Uji Hipotesis

1.3.1 Tingkat Signifikansi (α)

α adalah batas peluang kesalahan Tipe I yang bersedia kita tanggung – peluang menolak H0 padahal H0 benar. Nilai yang umum: 0,05; 0,01; atau 0,10. α ditetapkan sebelum data dianalisis, berdasarkan seberapa mahal akibat kesalahan Tipe I.

1.3.2 Statistik Uji

Statistik uji mengukur seberapa jauh estimasi sampel dari nilai H0, dalam satuan standard error:

Statistik uji = \(\)

\[ z = \]

z_hitung <- (xbar - mu0) / se
z_hitung
[1] -2.4

Rata-rata sampel berada 2.4 standard error di bawah nilai yang diklaim.

1.3.3 Nilai Kritis dan Daerah Penolakan

Nilai kritis adalah batas yang memisahkan daerah “tidak mengejutkan” dan daerah penolakan, ditentukan oleh α dan arah uji.

alpha <- 0.05
c(Dua_arah = qnorm(1 - alpha / 2), Kanan = qnorm(1 - alpha), Kiri = qnorm(alpha))
 Dua_arah     Kanan      Kiri

gambar_daerah <- function(arah, judul, alpha = 0.05) {
x <- seq(-4, 4, length.out = 400)
plot(x, dnorm(x), type = "l", lwd = 2, main = judul, xlab = "z", ylab = "", yaxt = "n")
arsir <- function(a, b) polygon(c(a, seq(a, b, length.out = 100), b),
c(0, dnorm(seq(a, b, length.out = 100)), 0),
col = rgb(0.8, 0.2, 0.2, 0.5), border = NA)
if (arah == "dua") { k <- qnorm(1 - alpha / 2); arsir(-4, -k); arsir(k, 4) }
if (arah == "kanan") { k <- qnorm(1 - alpha); arsir(k, 4) }
if (arah == "kiri") { k <- qnorm(alpha); arsir(-4, k) }
}
par(mfrow = c(1, 3))
gambar_daerah("dua", "Dua arah (1,96)")
gambar_daerah("kanan", "Kanan (1,645)")
gambar_daerah("kiri", "Kiri (-1,645)")
par(mfrow = c(1, 1))

Daerah merah adalah daerah penolakan, luasnya α = 0,05. Pada uji dua arah, α dibagi dua ke kedua ekor.

Kita bungkus perhitungan uji z satu sampel dalam sebuah fungsi agar dapat dipakai ulang.

uji_z <- function(xbar, mu0, sigma, n, arah = c("dua", "kanan", "kiri"), alpha = 0.05) {
arah <- match.arg(arah)
z <- (xbar - mu0) / (sigma / sqrt(n))
p <- switch(arah, dua = 2 * (1 - pnorm(abs(z))), kanan = 1 - pnorm(z), kiri = pnorm(z))
kritis <- switch(arah, dua = qnorm(1 - alpha / 2), kanan = qnorm(1 - alpha), kiri = qnorm(alpha))
data.frame(z = round(z, 4), z_kritis = round(kritis, 4), p_value = signif(p, 4),
keputusan = ifelse(p <= alpha, "Tolak H0", "Gagal menolak H0"))

}

1.4.1 Contoh 1 (Dua Arah): Mesin Pengisi Kopi

  1. H0∶ μ = 250 gram (mesin tepat); H1∶ μ ≠ 250 gram (mesin perlu dikalibrasi).
  2. α = 0,05.
  3. σ diketahui (6 g), n = 36, uji z: z = (247,6 − 250)/1 = −2,4.
uji_z(xbar = 247.6, mu0 = 250, sigma = 6, n = 36, arah = "dua")
     z z_kritis p_value keputusan
1 -2.4     1.96  0.0164  Tolak H0

  1. |z| = 2,4 > 1,96 dan p-value ≈ 0,016 < 0,05 ⇒ tolak H0.

  2. Kesimpulan: pada taraf signifikansi 5%, terdapat bukti yang cukup bahwa rata-rata pengisian mesin berbeda dari 250 gram (data menunjukkan cenderung kurang). Mesin sebaiknya diperiksa dan dikalibrasi.

1.4.2 Contoh 2 (Satu Arah Kanan): Klaim Waktu Pengiriman

Sebuah layanan logistik mengklaim rata-rata waktu pengirimannya paling lama 48 jam. Asosiasi konsumen curiga waktunya lebih lama. Data historis menunjukkan σ = 10 jam. Sampel 50 pengiriman menghasilkan ̄x = 50,1 jam.

  1. H0∶ μ ≤ 48 (klaim benar); H1∶ μ > 48 (klaim tidak benar – lebih lama).
  2. α = 0,05.
uji_z(xbar = 50.1, mu0 = 48, sigma = 10, n = 50, arah = "kanan")
       z z_kritis p_value        keputusan
1 1.4849   1.6449 0.06878 Gagal menolak H0

Kesimpulan: p-value ≈ 0,069 > 0,05, sehingga gagal menolak H0. Pada taraf 5%, bukti belumcukup untuk menyatakan rata-rata waktu pengiriman melebihi 48 jam. Ini tidak membuktikan klaim perusahaan benar; dengan p-value 0,07, ada indikasi lemah yang layak ditindaklanjuti dengan sampel lebih besar.

Perhatikan: jika asosiasi konsumen memakai uji dua arah, p-value-nya menjadi dua kali lipat (sekitar 0,14). Arah uji harus ditentukan dari pertanyaan penelitian sebelum melihat data.

1.5 Hubungan Uji Dua Arah dan Selang Kepercayaan

Uji dua arah dengan taraf α setara dengan memeriksa apakah μ0 berada di dalam selang kepercayaan (1 − α) × 100%:

• μ0 di luar CI 95% ⟺ tolak H0 pada α = 0,05 (dua arah).

• μ0 di dalam CI 95% ⟺ gagal menolak H0

ci <- 247.6 + c(-1, 1) * qnorm(0.975) * 6 / sqrt(36)
round(ci, 3)
[1] 245.64 249.56
250 >= ci[1] & 250 <= ci[2] # FALSE -> 250 di luar selang -> konsisten dengan "tolak H0"
[1] FALSE

Selang kepercayaan lebih informatif: selain keputusan, ia menunjukkan rentang nilai μ yang masuk akal – di sini rata-rata pengisian kemungkinan antara 245.6 dan 249.6 gram, sehingga kekurangannya kemungkinan antara 0.4 dan 4.4 gram per kemasan.

1.6.3 Simulasi: Kesalahan Tipe II dan Power

Sekarang anggap mesin benar-benar mengisi rata-rata 248 gram (H0 salah). Seberapa sering uji kita mendeteksinya ?

power_sim <- function(mu_benar, n, alpha = 0.05, B = 5000) {
mean(replicate(B, {
z <- (mean(rnorm(n, mu_benar, 6)) - 250) / (6 / sqrt(n))
2 * (1 - pnorm(abs(z))) <= alpha
}))
}
power_teori <- function(mu_benar, n, alpha = 0.05) {
k <- qnorm(1 - alpha / 2); d <- (mu_benar - 250) / (6 / sqrt(n))
pnorm(-k - d) + 1 - pnorm(k - d)
}

1.8.4 Pertanyaan Diskusi dan Jawaban

  1. Apa kesimpulan rumusan A?

P-value = 0.0766. Pada taraf 5% bukti belum cukup untuk menyatakan rata-rata TSS melebihi 50 mg/L, meskipun rata-rata sampel di atas baku mutu.

  1. Mengapa rumusan B lebih “protektif” terhadap lingkungan?

Pada rumusan B, kesalahan yang dikendalikan ketat (α = 5%) adalah menyatakan patuh pada- hal melanggar. Beban pembuktian ada pada perusahaan: rata-rata sampel harus cukup jauh di bawah 50 mg/L agar dinyatakan patuh. Pada data ini, rumusan B jelas gagal membuktikan kepatuhan.

  1. Mengapa power penting bagi regulator?

Dengan rumusan A dan n = 30, pelanggaran nyata sebesar 5 mg/L hanya terdeteksi sekitar 74% dari waktu. Sisanya lolos. Menambah sampel menjadi 60 menaikkan power menjadi sekitar 94%. Keputusan jumlah sampel pemantauan adalah keputusan tentang seberapa sering pelanggaran boleh lolos.

  1. Apa pelajaran umumnya? Rumusan H0 menentukan siapa yang diuntungkan oleh keraguan. Pilihan itu harus didasarkan pada konsekuensi kesalahan di dunia nyata, ditetapkan sebelum data dilihat, dan dilaporkan secara terbuka.

Soal D. Sebuah tim menguji 15 variasi warna tombol terhadap warna lama, masing-masing dengan α = 0,05, dan melaporkan satu variasi yang “signifikan” (p = 0,03). Berapa peluang setidaknya satu hasil signifikan jika sebenarnya tidak ada variasi yang lebih baik? Apakah temuan itu meyakinkan dengan koreksi Bonferroni?

1.10 Kesalahan Umum dalam Uji Hipotesis

  1. Menulis hipotesis tentang statistik sampel (H0∶ ̄x = 250) – hipotesis selalu tentang parameter.

  2. Menaruh kesamaan di H1 – tanda =, ≤, ≥ selalu berada di H0.

  3. Memilih arah uji setelah melihat data – p-value menjadi tidak sah.

  4. “Menerima H0” – yang benar adalah “gagal menolak H0”; ketiadaan bukti bukan bukti ketiadaan.

  5. Menafsirkan p-value sebagai peluang H0 benar.

  6. Menyamakan signifikansi statistik dengan kepentingan praktis – selalu laporkan besar efek dan CI.

  7. Menetapkan α setelah melihat p-value agar hasilnya “signifikan”.

  8. Menguji banyak hipotesis tanpa koreksi – peluang false positive melonjak.

  9. Mengabaikan power – studi dengan sampel kecil sering gagal mendeteksi efek nyata, lalu disimpulkan “tidak ada efek”.

  10. Hanya menulis “tolak H0” tanpa kesimpulan dalam konteks – pembaca perlu tahu artinya bagi masalah nyata.

  11. Mengabaikan konsekuensi dunia nyata saat merumuskan H0 – rumusan menentukan siapa yang diuntungkan oleh keraguan.

1.13 Rangkuman dan Kesimpulan

  1. Logika uji hipotesis sama dengan pengadilan: asumsikan H0 benar, lalu nilai seberapa mengejutkan data; tolak H0 hanya jika bukti kuat.

  2. Hipotesis dinyatakan tentang parameter; H0 selalu memuat kesamaan; arah uji ditentukan dari pertanyaan penelitian sebelum melihat data.

  3. Statistik uji mengukur jarak estimasi dari H0 dalam satuan SE. Keputusan dapat diambil dengan nilai kritis atau p-value – keduanya setara.

  4. P-value adalah peluang hasil seekstrem ini jika H0 benar – bukan peluang H0 benar.

  5. Kesalahan Tipe I (α) dan Tipe II (β) saling tarik-menarik; hanya sampel lebih besar yang dapat mengurangi keduanya sekaligus. Rancang studi dengan power memadai.

  6. Signifikan secara statistik belum tentu penting secara praktis; laporkan besar efek dan selang kepercayaan, dan waspadai uji berganda.

Jembatan ke sesi berikutnya: hari ini kita memakai uji z dengan σ diketahui sebagai kendaraan untuk memahami konsep. Pertemuan 11 membahas situasi yang jauh lebih sering dijumpai – σ tidak diketahui – dengan uji t satu sampel, dua sampel independen, dan berpasangan, beserta uji z dua sampel.
